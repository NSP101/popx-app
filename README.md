# PopX React App

A simple multi-page React app demonstrating a welcome screen, sign-in, create account, and account settings pages with bottom-aligned navigation.

## Features

- **Welcome Screen**:   
  - Create Account and Login buttons  
  - Bottom-aligned buttons for better user experience  

- **Sign In Page**:  
  - Email and password input  
  - Login button  

- **Create Account Page**:  
  - Full Name, Phone Number, Email, Password, Company Name inputs  
  - Agency selection (Yes/No)  
  - Create Account button  

- **Account Settings Page**:  
  - Profile image, name, and email  
  - Description text  
  - Clean layout with dotted separators  

- **Bottom Navigation**:  
  - Home, Previous, Next buttons  
  - Page indicator (e.g., `1 of 4`)  

## Tech Stack

- React.js  
- Tailwind CSS  
- React Icons
